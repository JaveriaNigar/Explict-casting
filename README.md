# TypeScript Explicit Casting Practice

This repository contains practice code demonstrating **explicit type casting** in TypeScript (using `as` keyword / angle‑brackets) as part of learning type handling.  

## 🧰 Technologies Used
- TypeScript  

## 📌 What you’ll find
- `index.ts` file with example of casting variables to different types  
- Comments explaining when and why explicit casting is used  

## 🚀 How to Run
1. Clone the repository  
2. Navigate to the folder  
3. Run `tsc index.ts` (if TS installed) or open in online TS playground  
4. Review the code and experiment with changing cast types
